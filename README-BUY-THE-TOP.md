# BUY THE TOP — fixed MVP

This ZIP contains the existing v0 project with the Supabase bid flow corrected.

Key fixes:
- Reads `website_url` (the actual database column).
- Uses `place_bid()` RPC instead of direct INSERT.
- Supports the Supabase publishable key variable generated by v0.
- Waits for the database response before showing “You're #1!”.
- Displays database errors instead of falsely reporting success.

Required environment variables:
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY (or NEXT_PUBLIC_SUPABASE_ANON_KEY)

The Supabase database must already contain the `entries` table and `place_bid()` function created during setup.
